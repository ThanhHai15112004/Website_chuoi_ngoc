description: Workflow Phát Triển Tính Năng Mới (Custom MVC)
---

Bước 1: Cơ Sở Dữ Liệu (Database)Mọi tính năng thường bắt đầu từ việc định nghĩa dữ liệu.Thiết kế bảng: Viết script SQL tạo bảng mới nếu cần (lưu vào thư mục databases/migrations/ để theo dõi). Lưu ý Khóa chính: Luôn set Primary Key là id với kiểu VARCHAR(36) để chứa UUID. Foreign Keys: Đảm bảo ràng buộc toàn vẹn dữ liệu nếu có liên kết với các bảng như nguoi_dung, san_pham. Bước 2: Tạo Model (Data Access Layer)Model chỉ chịu trách nhiệm tương tác với Database bằng PDO. Vị trí: Tạo file tại app/Models/Admin/TenModel.php (Lưu ý: Trang khách hàng cũng dùng chung Model ở thư mục Admin). Logic:Sử dụng Singleton kết nối DB: Database::getInstance()->getConnection(). Viết các hàm thực thi query bằng PDO (Prepared Statements).Tuyệt đối không nhồi nhét logic tính toán nghiệp vụ ở đây.
Bước 3: Tạo Service (Business Logic Layer)Đây là "trái tim" của tính năng, nơi xử lý nghiệp vụ, giúp Controller mỏng và gọn.Vị trí: Tạo file tại app/Services/Admin/TenService.php (hoặc User/TenService.php). Logic:Import và gọi các hàm từ Model.Tự động sinh UUID bằng PHP trước khi truyền dữ liệu xuống Model để Insert.Xử lý tính toán (ví dụ: tính giá sau giảm, gọi MailHelper gửi email, kiểm tra điều kiện).  
Bước 4: Tạo Controller (Request Handling)Controller làm nhiệm vụ điều phối, nhận Request và trả về Response.Vị trí: Tạo file tại app/Controllers/Admin/TenController.php (hoặc User). Logic:Class phải extends \App\Core\Controller. Nhận dữ liệu từ $\_GET, $\_POST, thực hiện validate cơ bản.Gọi Service để lấy kết quả.Trả về view bằng phương thức của base controller: return $this->view('pages/ten_view', $data, 'admin'); (truyền đúng layout là admin hoặc main). Bước 5: Khai Báo Route (Định tuyến)Khai báo URL để trỏ vào Controller vừa tạo.Vị trí: Mở file routes/admin.php hoặc routes/web.php. Logic:Định nghĩa route theo pattern regex hiện tại của file Router.php. Ví dụ cho Admin: /admin/ten-module -> TenController@index.Nếu là API trả JSON, đặt prefix rõ ràng: /admin/ten-module/api/....  
Bước 6: Xây Dựng View & Components (UI)Hiển thị giao diện người dùng.Vị trí: Tạo file PHP tại views/pages/ten_thu_muc/ và chia nhỏ UI vào views/components/. Logic:Admin: Sử dụng class Tailwind thoải mái vì layout admin.php dùng CDN. User: Đảm bảo class Tailwind đã được compile qua CLI vào style.css vì layout main.php dùng file build. Sử dụng helper component('TenComponent', $data) để tái sử dụng các khối UI (như modal, bảng, toast). Tóm tắt luồng đi dữ liệu khi code chạy:Route ➔ Controller ➔ Service ➔ Model ➔ MySQL ➔ Model ➔ Service ➔ Controller ➔ View (layout + component).
